# Nexora World-Class Ecommerce Frontend

Static ecommerce frontend built with HTML, CSS and vanilla JavaScript.

## Pages
- Home: 3-slide animated hero, product highlights, categories, services, testimonials, CTA, auto-playing client strip.
- Shop: search, category filtering, price sorting, responsive product cards.
- Product: dynamic product detail via `product.html?id=1`, quantity control, add-to-cart and buy-now.
- Cart: persistent localStorage cart, quantity controls, shipping calculation and checkout CTA.
- Checkout: delivery form, order summary, demo order generation and tracking reference.
- Tracking: order-reference tracking flow.
- About, Services, Contact/Support: supporting brand pages with 6+ sections each.

## Tech
HTML5 + CSS3 + Vanilla JavaScript. No framework required.
